# AI UI — رابط فارسی چت و سشن‌های Codex

برنامه‌ای محلی با رابط راست‌به‌چپ برای چت، ضبط ویس و ادامهٔ گفتگوهای پروژه‌ای Codex.

## امکانات

- نمایش سشن‌های محلی بر اساس پروژه و ادامهٔ همان گفتگو با ابزارهای Codex
- نمایش پیشرفت کار، درخواست اجازه، سؤال‌های Codex و توقف اجرا
- آرشیو، بازیابی و حذف گفتگو با تأیید صریح
- چت عادی با ارائه‌دهندهٔ سازگار با OpenAI Responses API
- ضبط ویس با تایمر و پخش قبل از ارسال
- ضمیمهٔ تصویر، PDF، متن و Excel
- کادر ارسال کوچک، اسکرول مستقل گفتگو و نمایش مصرف توکن
- Enter برای ارسال؛ Shift+Enter برای خط بعد

## پیش‌نیازها

- Node.js نسخهٔ ۲۰ یا بالاتر و npm
- Codex نصب‌شده و ورود به حساب برای سشن‌های پروژه‌ای
- فایل `~/.codex/config.toml` با مدل و ارائه‌دهندهٔ دلخواه
- Chrome یا Edge و دسترسی میکروفون برای ویس

راهنمای رسمی: [تنظیمات Codex](https://learn.chatgpt.com/docs/config-file/config-reference) و [App Server](https://learn.chatgpt.com/docs/app-server).

## نصب و اجرا

```sh
git clone https://github.com/codeup70/ai-ui.git
cd ai-ui
npm ci
```

فایل `.env.example` را به `.env` کپی کنید و در صورت نیاز تنظیماتش را تغییر دهید.

```sh
npm start
```

آدرس: `http://localhost:3000`. در ویندوز پس از نصب وابستگی‌ها می‌توانید از `start.bat` استفاده کنید.

این برنامه برای اجرای شخصی روی رایانهٔ خودتان است؛ سرور روی `127.0.0.1` گوش می‌دهد و سرویس چندکاربرهٔ اینترنتی نیست.

## تنظیمات

| متغیر در `.env` | کاربرد |
| --- | --- |
| `PORT` | پورت؛ پیش‌فرض `3000` |
| `CODEX_HOME` | پوشهٔ تنظیمات و سشن‌های Codex؛ پیش‌فرض `~/.codex` |
| `CODEX_CONFIG_PATH` | فایل تنظیمات جایگزین برای چت عادی؛ محل سشن‌ها را تغییر نمی‌دهد |
| `CODEX_BIN` | مسیر فایل اجرایی Codex، اگر تشخیص خودکار یا PATH کافی نیست |
| `OPENAI_API_KEY` | کلید چت عادی، در صورت نیاز ارائه‌دهنده |

برنامه از `model`، `model_reasoning_effort`، `model_provider` و پروفایل پیش‌فرض Codex استفاده می‌کند. ارائه‌دهندهٔ چت عادی باید Responses API را پشتیبانی کند. `base_url`، `env_key`، `experimental_bearer_token` و هدرهای تنظیم‌شده پشتیبانی می‌شوند. کلیدها روی سرور می‌مانند.

ورود به حساب Codex برای سشن‌های پروژه‌ای استفاده می‌شود؛ لزوماً کلید لازم برای چت عادی را فراهم نمی‌کند. هر کاربر باید احراز هویت ارائه‌دهندهٔ خودش را تنظیم کند. هیچ کلید، حساب یا تنظیمات شخصی همراه مخزن نیست.

پس از تغییر تنظیمات یا کد سرور، برنامه را دوباره اجرا و صفحه را تازه کنید.

## سشن‌های پروژه‌ای

سشن‌های همین رایانه با رابط رسمی `codex app-server` خوانده می‌شوند. ارسال پیام، همان شناسهٔ سشن و مسیر پروژه را ادامه می‌دهد. تنظیمات مجوز و sandbox دور زده نمی‌شوند و پایگاه دادهٔ Codex مستقیماً ویرایش نمی‌شود.

تاریخچه هر دو ثانیه و فهرست سشن‌ها هر ۳۰ ثانیه تازه می‌شود. چت‌های عادی مرورگر جدا نگه داشته می‌شوند. سشن‌های دستگاه‌های دیگر یا تاریخچهٔ صرفاً ابری دریافت نمی‌شوند.

ابتدا کار فعال یک سشن را در برنامهٔ دسکتاپ تمام کنید و سپس اینجا ادامه دهید؛ این رابط یک پردازش app-server جداگانه دارد. درخواست ابزارهای مخصوص کلاینت که پشتیبانی نمی‌شوند با خطای واضح متوقف می‌شوند.

آرشیو تاریخچه را برای بازیابی نگه می‌دارد. از بخش «آرشیوشده‌ها» می‌توانید گفتگو را بازیابی کنید. حذف سشن پس از تأیید، تاریخچهٔ آن و سشن‌های فرزندش را دائماً حذف می‌کند. حذف چت عادی و پاک‌کردن پیام‌ها هم تأییدیه دارند.

## ویس و فایل‌ها

ویس تا پنج دقیقه ضبط و قبل از ارسال قابل پخش و حذف است. صوت در IndexedDB مرورگر ذخیره می‌شود؛ فایل‌های قدیمی‌تر از ۲۴ ساعت هنگام بازکردن بعدی برنامه پاک می‌شوند. تشخیص گفتار هم‌زمان در پس‌زمینه انجام می‌شود و ممکن است از سرویس آنلاین سازندهٔ مرورگر استفاده کند. فقط متن ویس پس از ارسال به ارائه‌دهندهٔ چت فرستاده می‌شود.

حداکثر پنج ضمیمه در هر پیام: تصویر PNG/JPEG/WebP تا ۸ مگابایت، PDF تا ۳۲ مگابایت، متن/کد تا ۱ مگابایت و Excel تا ۸ مگابایت. پیش‌نمایش Excel تا ۲۰۰ ردیف در هر شیت است. PDF در سشن‌های Codex با مسیر محلی معرفی می‌شود؛ خواندن آن تابع ابزارها و مجوزهای Codex است.

چت‌های عادی در localStorage و ضمیمه‌ها در `uploads/` ذخیره می‌شوند. محتوای ضمیمه‌ها هنگام استفاده در گفتگو در اختیار ارائه‌دهنده قرار می‌گیرد. فایل `.env`، آپلودها، تاریخچه‌ها و حافظهٔ شخصی عامل نباید وارد گیت شوند.

## تست‌ها

```sh
npm test
```

تست‌های واحد به حساب واقعی نیاز ندارند و هیچ سشن واقعی را حذف نمی‌کنند.

تست‌های اختیاری فقط‌خواندنی با Codex نصب‌شده و سشن محلی:

```sh
npm run test:codex
npm run test:browser
```

تست مرورگر به Chrome/Chromium نیاز دارد؛ در صورت نیاز مسیر آن را با `CHROME_BIN` مشخص کنید. این تست‌ها پیامی به مدل نمی‌فرستند.
